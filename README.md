# Blogrlandingpage

A fully responsive landing page built as part of the Web Design Capstone Project, based on the [Frontend Mentor Blogr challenge](https://www.frontendmentor.io/challenges/blogr-landing-page-EX2RLAApP).

## Project Structure

```
blogr/
├── index.html          # Main HTML
├── css/
│   └── style.css       # All styles (variables, layout, components, responsive)
├── js/
│   └── main.js         # Nav toggle, dropdowns, scroll reveal
├── images/
│   └── icon-arrow-light.svg
└── README.md
```

## Features

- ✅ Fully responsive (Mobile 375px → Desktop 1440px)
- ✅ Mobile hamburger navigation with slide-down menu
- ✅ Dropdown navigation menus (desktop hover + mobile tap)
- ✅ CSS-only device mockups (phone + laptop illustrations)
- ✅ Scroll reveal animations (IntersectionObserver)
- ✅ Hero fade-up animation on load
- ✅ Semantic HTML / accessible markup
- ✅ WCAG-compliant color contrast
- ✅ CSS custom properties (design tokens)
- ✅ Clean file organization

## Tech Stack

- HTML5 (semantic elements)
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (no dependencies)
- Google Fonts: Overpass + Ubuntu
